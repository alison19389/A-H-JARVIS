# A-H JARVIS — Android

Projeto inicial de um assistente virtual para Android usando Kotlin + Jetpack Compose.

## Como abrir

1. Instale o Android Studio.
2. Abra a pasta `AHJarvis`.
3. Aguarde o Gradle sincronizar.
4. Conecte um celular Android ou use um emulador.
5. Execute o app.

## O que já funciona

- Interface escura estilo assistente futurista.
- Reconhecimento de voz usando o mecanismo do Android.
- Respostas faladas com Text-to-Speech.
- Comandos básicos de hora e conversa.
- Estrutura preparada para conectar uma API de IA.

## Próxima etapa

Para transformar isso em um assistente de IA completo, é preciso adicionar um backend seguro para chamar uma API de modelo de linguagem. A chave da API não deve ser colocada diretamente no APK.
